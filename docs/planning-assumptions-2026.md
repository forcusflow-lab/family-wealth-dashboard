# 今月・将来計画の前提と出所

## 教育費

教育費の時期は、保存済みの子どもの年齢から高校を15歳、大学を18歳の到達時期として機械的に表示する。初期の仮置き額は、文部科学省の令和5年度「子供の学習費調査」における私立高校の年間学習費 **1,030,283円**、および日本学生支援機構（JASSO）令和6年度「学生生活調査」における東京圏（埼玉県を含む）・私立大学・自宅通学者の年間学生生活費 **1,986,700円**とする。後者は学費と生活費を合わせた標本推計である。進路、授業料支援、物価、入学初年度費用、奨学金は別途更新が必要である。

アプリでは比較用の保守的ストレス額を、各教育基準額の **120%** として表示する。これは物価・学部差・学校固有費用の余裕をみるアプリ内の仮定であり、公的統計の上限値ではない。

既存現金は生活防衛資金を先に確保し、残りを期限の近い教育資金へ順番に仮充当する。各期限までの不足額を月割りで現金積立し、住宅維持・年払いも差し引いた残余だけをiDeCo、次いで長期運用の候補とする。年収は保存済みの源泉徴収票由来の本人給与を基礎にしており、配偶者収入、賞与、臨時支出、学資支援は確認済みの数値がない限り余剰資金へ自動算入しない。

## 住宅メンテナンス

住宅維持の月額目安は、保存済みの維持目標額を保存済みの積立年数で割った家計上の積立案である。住宅金融支援機構は木造一戸建てを含む一般的な維持管理の目安を示す一方、工法、仕様、地域気候で点検・補修時期は異なると明記している。そのため、アプリは平均的な工事費を保証せず、点検記録、保証期限、実際の見積書を優先する。

初期の住宅維持目標は **10年で2,000,000円**、比較用ストレス額は **4,000,000円**（基準の2倍）とする。住宅金融支援機構の資料は点検・補修の時期と記録を示す一次資料だが、戸建住宅向けの一律費用単価は示していない。住宅リフォーム推進協議会の実態調査は実施者のリフォーム費用・工事内容を示す業界資料であり、単一の戸建住宅の必要額へ直接当てはめない。したがって、2,000,000円から4,000,000円は市場平均ではなく、見積書取得前の家計上の仮置きレンジである。

## 住宅ローン金利

埼玉りそなの変動金利型について、公式説明は4月・10月の金利見直し、3か月後の適用、5年ごとの返済額見直し、125%上限の仕組みを説明している。アプリの返済額は残高・現在金利・残存年数からの単純な元利均等再計算であり、契約上の返済予定表を代替しない。金利通知後は、利用者が適用金利を手動入力し、アプリ上で資金余力と提案を再計算する。
