# 推奨エンジンの制度・税制前提

**参照日:** 2026-08-17（JST）

| 前提 | アプリでの扱い | 参照・注意点 |
| --- | --- | --- |
| iDeCo掛金 | 年間掛金を所得控除の対象として税制比較に表示する。 | 国税庁は個人型年金加入者掛金を小規模企業共済等掛金控除の対象とし、その年に支払った掛金の全額を控除額とする。[1] 実際の節税額は課税所得・他控除で変わる。 |
| NISA | 長期資金での非課税保有枠として比較する。 | 金融庁のNISA特設サイトを参照。個別商品の期待収益や非課税枠の使い切りを保証するものではない。[2] |
| 住宅ローン控除 | 残高×控除率の単純上限を、繰上返済の比較時に示す。 | 所得税・住民税の控除余地や契約条件で実額は変わるため、年末残高証明書・源泉徴収票で年次確認が必要。 |
| 確率モデル | 5,000経路の再現可能な疑似乱数で資産クラスの配分候補を比較する。 | 年率リターン・変動率・インフレ・収入減少・金利ショックはモデル仮定であり、予測や保証ではない。 |

## 参照

[1] [国税庁「No.1135 小規模企業共済等掛金控除」](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1135.htm)

[2] [金融庁「NISA特設ウェブサイト」](https://www.fsa.go.jp/policy/nisa2/)
