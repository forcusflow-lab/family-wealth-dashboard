# 口座台帳と目的別配分の設計

## 目的

口座数が多くても、月に一度、各口座の**現金残高だけ**を入力すれば、家計の全体像と次に取るべき資金行動が分かるようにする。証券の保有商品・評価額は既存のNISA／投資資産として別管理し、この台帳には預金・証券口座内の待機現金のみを登録する。

## 口座の用途

| 用途 | 扱い | 自動配分 |
|---|---|---|
| 給与・引落 | 日常支出用の口座。今月の生活・住宅ローン相当額を残す | 超過分だけ未割当に回す |
| 生活防衛・年払い・教育・住宅 | 目的が決まった現金 | 他用途へ自動振替しない |
| 老後・投資待機 | 長期用途として自ら分けた現金 | 近期限資金の不足を理由に勝手に売却・移動しない |
| 未割当 | まだ使い道を決めていない現金 | 生活防衛、年払い、近期限教育、住宅の順に仮想配分する |

## 表示の約束

月次画面では、口座の実残高と資金計画を次の5区分で表示する。

1. **目的指定済み**は、利用者が付けた用途のまま保持する。
2. **未割当現金**だけを安全順に仮想配分する。
3. **現金目標**は、口座へ置く最終残高である。
4. **今月追加**は、目的別の不足を埋める今月の振替目安であり、投資額ではない。
5. **iDeCo／NISA**は、現金目標と今月の余裕資金を満たした場合にのみ、別行で設定額を表示する。追加の一括投資・注文・振替は実行しない。

> 口座名と目的はいつでも修正できる。月1回の残高入力は、明細・パスワード・外部連携を必要としない。
