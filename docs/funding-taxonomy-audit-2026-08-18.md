# 月次資金計画の全体監査

## 監査結果

既存の実装では、同じ金額を**将来の総費用**、**現在確保すべき現金目標**、**今月の現金移動額**として別々の画面で混在させていた。このため、教育資金のように現金化時期がまだ来ていない目的に「目標0円」が表示され、年払い・住宅維持は既存現金へ仮想配分済みでも月額積立に全額計上され得た。また、月次の長期運用候補は保存済みNISA積立額との関係が明示されていなかった。

| 監査対象 | 問題 | 修正方針 |
| --- | --- | --- |
| 教育資金 | 5年超の長期計画を現金バケツとして出力し、目標0円という表示を生んだ。 | 現金バケツから外し、「長期教育計画」として開始時期・総見込・現金化開始時期だけを表示する。 |
| 年払い費用 | 固定資産税・旅行・保険の年間目標が現金の仮想配分に含まれず、月次積立と二重に見えた。 | 年払いを現金目的として独立し、現在配分・年度目標・今月の追加額を分ける。 |
| 住宅維持 | 既存現金で一部又は全部を確保しても、10年均等の月額を常に加算した。 | 現在不足額だけを残存期間で月割りし、充足時は今月の追加額を0円と明示する。 |
| 投資候補 | iDeCo・保存済みNISA積立・追加の長期余剰が一つの「長期運用候補」に混在した。 | iDeCo、NISA定額、追加余剰を別表示し、総額と追加額を混同しない。 |
| 画面・タスク | 「確保する」「積み立てる」「目標」が同一行に混在した。 | 各目的で「現在確保済み」「最終現金目標」「今月追加」「期限」「次の一手」の5項目に統一する。 |

## 統一する用語

| 用語 | 定義 |
| --- | --- |
| **現在確保済み** | 保存済みの実残高を、安全優先順で目的別に仮想配分した金額。 |
| **現金目標** | 支出時期に備え、価格変動資産ではなく確保する最終金額。 |
| **今月追加** | 現在の不足額を残存期間で埋めるため、この月に現金へ移す目安。充足済みなら0円ではなく「追加不要」と表示する。 |
| **将来計画** | 5年超など、まだ現金化開始前の総費用見込。現金不足・今月追加としては扱わない。 |
| **投資余剰** | 現金目標に対する今月追加と余裕資金を差し引いた後に残る、長期目的だけへ使える候補額。 |

## 検証方針

各計算で、目的ごとの現在確保済み・現金目標・不足額・今月追加・期限を同じ共通モデルから生成する。ゼロの現金目標はカードとして出力せず、長期計画セクションへ分類する。投資候補は、iDeCo、NISA定額、追加余剰を別々に検証する。
