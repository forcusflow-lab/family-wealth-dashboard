# NISA比較範囲・出所メモ

**基準日:** 2026-08-18 JST

## 比較範囲

NISA対象商品は多数あり、全商品の将来成績を予測して単一順位を付けることはしない。本アプリでは、金融庁のつみたて投資枠届出一覧、資産運用業協会の成長投資枠届出一覧、東京証券取引所の成長投資枠対象ETF一覧を母集団の公式根拠とする。比較は、既存保有の役割を代替できる**低コスト・広範囲分散コア**、為替ヘッジ有無の代替、債券・金などの**サテライト**、および現行保有との重複に絞る。

金融庁のつみたて投資枠対象商品届出一覧は2026-08-10更新であり、運用会社別・対象資産別Excelを公表している。成長投資枠の国内籍投信・ETF・REITは資産運用業協会が届出ベースで取りまとめ、非上場投信は2026-08-14、上場ETF・REIT等は2026-07-24更新としている。対象商品は変更され得るため、実際の買付前には証券会社画面でNISA対象可否を再確認する。

公式Excelの確認では、金融庁のつみたて投資枠は指定インデックス投信286本、指定インデックス以外のアクティブ投信等66本、ETF9本で構成される。資産運用業協会の成長投資枠一覧は、非上場ファンドの現行一覧と削除予定・履歴、上場ファンドの現行一覧と削除予定・履歴を分け、ファンドコード・名称・運用会社・設定日・償還日・成長投資枠取扱可能日・決算回数・つみたて投資枠対象可否を記載する。これは商品**適格性**の母集団であり、個別の将来収益の順位表ではない。
