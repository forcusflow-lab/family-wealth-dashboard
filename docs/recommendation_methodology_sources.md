## 比較範囲と非網羅性

アプリの比較は、**既存の5銘柄、SBI iDeCoセレクトプラン内の代表的な低コスト全世界株式候補、現金・NISA・iDeCo・繰上返済、ならびに株式／債券／金の3資産配分候補**に限る。全投資信託、全ETF、個別株、保険、外貨、暗号資産、レバレッジ商品を横断して最適化した結果ではない。

期待リターンは市場予言ではなく、各資産クラスの名目年率仮定と変動率を用いた確率シミュレーションの入力である。商品固有の将来年利を算定・保証するものではない。
