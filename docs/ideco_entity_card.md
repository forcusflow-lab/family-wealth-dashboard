# SBI証券 iDeCo セレクトプラン：候補ファンド確認

**確認日:** 2026-08-17（JST）

| 項目 | 内容 |
| --- | --- |
| 運営管理機関 | SBI証券 iDeCo セレクトプラン |
| 候補商品 | eMAXIS Slim 全世界株式（除く日本） |
| 資産クラス | 日本を除く世界株式のインデックス投信 |
| 連動対象 | 日本を除く世界株式に広く投資することを目指す指数 |
| 表示上の信託報酬 | 年率 0.05775% 以内（税込、SBI証券の商品一覧記載） |
| 選定理由 | 退職まで約27年の長期運用を前提に、低コストかつ広範な株式分散を一つの投信で実現できる。NISA保有の日本高配当株との地域重複を抑える意図がある。 |
| 月次案 | 20,000円を当該候補へ。実行前に加入者サイトで商品名・配分設定・信託報酬・2026年10月の取扱変更を再確認する。 |
| 主なリスク | 株式100%相当の値動き、為替変動、指数・信託報酬の改定、加入者サイトの取扱変更。元本保証ではない。 |
| 代替案 | 株式変動を下げたい場合は、eMAXIS Slimバランス（8資産均等型）または先進国債券等を組み合わせる。ただし、期待リターンと複雑性は変化する。 |

SBI証券の公式商品一覧は、eMAXIS Slim 全世界株式（除く日本）を含む商品・信託報酬を2025年6月25日時点として掲示している。SBIは2026年10月16日に商品追加・除外を予定しているため、設定実行時点の加入者サイトが最終確認手段となる。[1][2]
