# Family Wealth Dashboard

日本の世帯向けに、家計、目的別現金、NISA・iDeCo、住宅ローン、教育資金の見通しを一つの画面で確認するための個人資産管理アプリケーションです。月に一度、口座残高と基準日を更新し、現金目標、振替候補、月次の確認事項、将来試算をまとめて確認する設計です。

> **重要:** このリポジトリに含まれる初期プロフィールは架空のサンプルです。実際の家計情報、口座情報、認証情報、環境変数は公開リポジトリへ保存しないでください。本ソフトウェアは情報整理とシミュレーションを目的とするものであり、投資・税務・法律上の助言ではありません。

## 主な機能

- 目的別現金の進捗と期限リスクの可視化
- 実口座の残高・基準日管理と月次更新の完了記録
- 現金残高を上限とする振替候補の表示（振替や注文の実行はしません）
- NISA・iDeCo・住宅ローン・教育費を含む月次判断と将来試算
- 夫婦で確認できる月次チェックリスト

## 開発環境

| 項目 | 内容 |
|---|---|
| フロントエンド | React 19 / TypeScript / Tailwind CSS |
| バックエンド | Express / tRPC |
| データ | Drizzle ORM / MySQL または TiDB |
| テスト | Vitest |

```bash
pnpm install
pnpm check
pnpm test
pnpm dev
```

このプロジェクトは認証、データベース、実行時設定に対応した環境を前提としています。ローカル開発では、必要な環境変数を自身で安全に設定してください。`.env` ファイル、実口座データ、画面キャプチャ、ログはコミットしないでください。

## データと公開時の注意

このリポジトリの `server/initialProfile.ts` はUI確認用の架空データです。実際の利用ではログイン後の保存データを使用します。公開前には、Git履歴、コミット差分、Issue、スクリーンショット、エクスポートファイルに個人情報が含まれないことを確認してください。
